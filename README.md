# Risky Rolls privacy policy &amp; support

GitHub Pages site for App Store Connect, matching the Scorely legal repo.

Live URLs after Pages is enabled:

- https://scorelyapp.github.io/riskyrolls/privacy-policy.html
- https://scorelyapp.github.io/riskyrolls/support.html
- https://scorelyapp.github.io/riskyrolls/app-ads.txt

AdMob crawls `https://scorelyapp.github.io/app-ads.txt` (the hostname root),
which is served from the `scorelyApp.github.io` org Pages repo. The copy in
this project site is a fallback.
